# AlfaBot: автономная торговля на Альфа-Форекс

Бот торгует **через браузерный веб-терминал** `trade.alfaforex.ru/terminal`. Программу MetaTrader 5
ставить не нужно. Бот сам открывает терминал в скрытом браузере Chromium, входит в ваш счёт,
читает баланс, позиции и котировки и нажимает те же кнопки, что и вы: открывает сделки сразу со
стоп-лоссом и тейк-профитом, подтягивает стоп и закрывает позиции. Вы управляете им из **Telegram**.

```
 Yahoo Finance ──(история свечей)──┐
                                   ▼
 Telegram  ◄──уведомления──  AlfaBot (Python)  ──Playwright──►  Chromium  ──►  trade.alfaforex.ru/terminal
           ──команды──────►   стратегия + риск                                  (ваш счёт)
```

**Что проверено вживую.** Веб-терминал Альфы — это стандартный MT5 Web Terminal от MetaQuotes. Весь цикл
проверен на демо-счёте того же терминала MetaQuotes:
- вход, чтение баланса, позиций и котировок;
- открытие BUY и SELL сразу с SL/TP;
- перенос стопа и закрытие;
- 5-значные (EURUSD) и 3-значные (USDJPY) пары, пересчёт объёма через курс валют;
- полный цикл бота, когда он сам открывает и закрывает сделки.

Форма входа у Альфы такая же. Повторить проверку можно скриптом `scripts/web_smoke_test.py`, он работает
только на демо-счёте.

## ⚠️ Важно про безопасность

- По умолчанию бот работает в **бумажном режиме**: котировки настоящие, сделки виртуальные, в терминал ничего
  не отправляется. Результаты видны в Telegram по команде `/stats`.
- Режим **«Ордера на счёт»** — бот открывает сделки в терминале. На **демо-счёте** (виртуальные деньги) это
  безопасно: «Проверить вход» показывает, демо у вас счёт или реальный.
- На **реальном** счёте ордера уходят, только если дополнительно стоит галочка «Разрешить реальные деньги»
  (в файлах — `BOT_MODE=live` в `.env` и `account.allow_real: true` в `config.yaml`).
- Бот трогает только свои сделки, помеченные комментарием `alfabot`. Ваши ручные сделки он не закрывает.
- Прибыль не гарантирует ни одна стратегия. Сначала 2–4 недели гоняйте бумажный режим, потом начинайте с малого
  риска.

## Быстрый старт на своём компьютере (Windows)

1. **Скачайте бота:**
   [ZIP-архив](https://github.com/01212804447a-pixel/finance/archive/refs/heads/claude/zen-bohr-17bdcp.zip).
   Распакуйте его, например, в `C:\AlfaBot`.
2. Дважды щёлкните **`1-install.bat`**. Он поставит Python (если его нет), нужные пакеты и браузер
   (примерно 5 минут). В конце сам откроется окно настроек.
3. В окне **«AlfaBot — настройка»** заполните поля сверху вниз:

   | Поле | Что вписать |
   |---|---|
   | Логин (номер счёта) | номер вашего счёта Альфа-Форекс, только цифры |
   | Пароль | пароль от этого счёта (тот же, что на trade.alfaforex.ru/terminal) |
   | Токен бота | токен от @BotFather, например `123456789:AA...` |
   | Мой chat_id | не вписывайте вручную: нажмите **«Найти мой chat_id»**, в открывшемся Telegram нажмите «Старт», и поле заполнится само. Бот пришлёт вам «✅ AlfaBot подключён» |
   | Валютные пары | можно оставить как есть |
   | Риск на сделку | 1 % — стандарт, 0.5 % — осторожнее |
   | Режим | **Бумажный** — сделки виртуальные. Если счёт демо, можно выбрать **«Ордера на счёт»**: сделки будут видны прямо в терминале |
   | Разрешить реальные деньги | не ставьте, пока не убедитесь в результатах |

   Затем нажмите **«Проверить вход»**. Через 1–2 минуты внизу появится ваш баланс и котировки.
   После этого нажмите **«Запустить бота»**.
4. Откроется чёрное окно **AlfaBot**: это и есть работающий бот. Пока оно открыто, бот торгует.
   Если закрыть окно, бот остановится. Чтобы запустить его снова, нажмите **`3-start.bat`**.
   Поменять настройки можно через **`2-settings.bat`**. Обновить бота до последней версии: закройте его окно
   и запустите **`4-update.bat`** (настройки сохранятся).

Советы для работы на своём компьютере:
- В настройках есть галочка «Запускать бота автоматически при включении компьютера».
- Отключите спящий режим (*Параметры → Система → Питание*): когда компьютер спит, бот не работает.
  При этом открытые сделки всё равно защищены стоп-лоссом и тейк-профитом на стороне брокера.
- Логин, пароль и токен хранятся только у вас, в файле `.env` в папке бота. Никому его не отправляйте.

**macOS/Linux:** выполните в терминале `./1-install.sh` (откроется то же окно настроек), затем запустите `./3-start.sh`.

## Запуск на сервере 24/7 (по желанию, позже)

Если не хочется держать компьютер включённым, арендуйте VPS на Linux (~300–600 ₽/мес).
Создайте на своём компьютере файлы `.env` и `config.yaml` через окно настроек и скопируйте их на сервер.
Затем:

```bash
docker compose up -d --build
```

Проверка без торговли и логи:

```bash
docker compose run --rm alfabot python run_web.py --check
```

```bash
docker compose logs -f
```

## Telegram

Токен даёт @BotFather (`/newbot`). chat_id окно настроек находит само по кнопке «Найти мой chat_id».

После каждой закрытой свечи (в торговые часы) бот присылает короткий отчёт: что он видит по каждой паре и почему
пока не входит. Отключается галочкой в настройках. Также бот присылает уведомления о каждом входе и выходе,
о срабатывании лимитов, итоги дня, а при ошибке — скриншот терминала. По субботам приходит рейтинг лаборатории
стратегий. Команды он принимает только из вашего чата:

| Команда | Действие |
|---|---|
| `/status` | баланс, средства, открытые позиции |
| `/market` | что бот видит по каждой паре и какого сигнала ждёт |
| `/lab` | рейтинг стратегий на новых данных (см. «Лаборатория стратегий») |
| `/stats` | статистика (в бумажном режиме — по виртуальным сделкам) |
| `/screenshot` | снимок веб-терминала прямо сейчас |
| `/pause` / `/resume` | остановить или возобновить открытие новых сделок |
| `/closeall` | закрыть все сделки бота и встать на паузу |

**Если Telegram или интернет сбоит**, бот продолжает торговать и сопровождать сделки как обычно: сообщения
не отправляются «на месте», а складываются в очередь на диске (`data/outbox`). Очередь переживает даже
перезапуск бота. Когда связь вернётся, все накопленные сообщения придут по порядку, склеенные в несколько
сообщений, с пометкой «⏳ отложено» и временем каждого события. Команды, отправленные боту больше 10 минут назад
(например, пока он был выключен), не выполняются вслепую: бот сообщит, что команда устарела.

## Переход на реальную торговлю

1. После нескольких недель в бумажном режиме проверьте `/stats`.
2. Откройте `2-settings.bat`, выберите **«Ордера на счёт»**, поставьте галочку **«Разрешить реальные деньги»**,
   при желании уменьшите риск и подтвердите.
3. Закройте окно бота и запустите `3-start.bat` заново.

## Стратегия и риск-менеджмент

Стратегия выбирается в окне настроек (или `strategy.name` в `config.yaml`):

| Стратегия | Как торгует | Сигналов |
|---|---|---|
| **`rsi2_d1`** — RSI(2) возврат к среднему, дневки (по умолчанию) | Покупает короткую просадку (RSI(2) < 10) при цене выше EMA200, продаёт короткий всплеск (RSI(2) > 90) ниже EMA200. Выход — когда цена вернулась за EMA5. Стоп 2 ATR, без тейка | ~1 в неделю на 3 пары |
| `momentum_12m` — импульс 12 месяцев, дневки | Всегда в рынке по направлению годового изменения цены, разворот при смене знака. Аварийный стоп 3 ATR | редко, сделки держатся неделями |
| `ema_cross` — пересечение EMA, часовки (старая) | EMA20/50 по тренду EMA200, ADX ≥ 20, стоп 1,5 ATR, тейк 3 ATR, трейлинг | ~0,5 в неделю на пару |

Дневные стратегии сигналят после закрытия дня (ночью по Москве). Бот не теряет такой сигнал: он входит, когда
открывается торговое окно, и держит позиции через выходные (это часть стратегии).

**Риск-менеджмент** (для всех стратегий):
- 1 % средств на сделку, объём считается автоматически, потолок `max_lot`;
- **дневной стоп −3 %**: бот закрывает всё и до завтра не торгует;
- **аварийная остановка при −15 % от пика**;
- не больше 3 позиций, фильтр спреда;
- новые сделки с 09:00 до 23:00 МСК, без новых сделок вечером в пятницу.

## Исследование стратегий: что работает в 2026 году

### Рынок, на котором торгует бот

- **Это рынок машин.** По опросу BIS 2025 года, 59 % валютных сделок исполняется электронно, на споте — 63 %.
  Оборот — $9,6 трлн в день ([BIS, 2025](https://www.bis.org/publ/qtrpdf/r_qt2512v.htm);
  [ФРБ Нью-Йорка](https://www.newyorkfed.org/medialibrary/media/markets/triennial/2025/2025triennialreport.pdf)).
  Против розничного бота работают банки, HFT-фирмы и всё больше ИИ-систем.
- **ИИ ускоряет рынок и делает его похожим на себя.** МВФ отмечает, что ИИ-торговля повышает оборот и
  корреляцию активов, быстрее «вшивает» новую информацию в цену и повышает риск «вспышек» волатильности; среди
  главных рисков — стадное поведение ([МВФ, GFSR окт. 2024, гл. 3](https://www.imf.org/en/publications/gfsr/issues/2024/10/22/global-financial-stability-report-october-2024);
  [блог МВФ](https://imf.org/en/Blogs/Articles/2024/10/15/artificial-intelligence-can-make-markets-more-efficient-and-more-volatile)).
  Исследования ИИ-агентов дают смешанную картину: в лабораторных опытах LLM-агенты стадны меньше людей
  ([arXiv 2510.01451](https://fugumt.com/fugumt/paper_check/2510.01451v1_enmode)), но когда они читают одни и те же
  источники, их решения синхронизируются ([ICLR 2026](https://iclr.cc/virtual/2026/10016534)).
- **Простые правила теханализа «съедены».** Обзор технических правил на валютах: средний коэффициент Шарпа упал
  с 0,66 на данных, где их подбирали, до 0,06 на новых, и прибыль не переживает даже скромных издержек
  ([Hutchinson и др., 2022](https://zenodo.org/records/7326524)). Кросс-секционный валютный импульс после 2008 года
  практически исчез ([Aalto, 2025](https://aaltodoc.aalto.fi/items/0db57fa9-e5c6-4b7d-9dd8-1ae15a8940c6)).
  Внутридневные эффекты (например, разворот после лондонского фиксинга в 16:00) статистически есть, но после
  издержек доступны в основном крупным игрокам с минимальными спредами
  ([Krohn, Mueller, Whelan](https://topcat.aeaweb.org/conference/2020/preliminary/paper/2dedYfDH)).
- **Итог для розничного трейдера:** по данным регуляторов ЕС, на CFD теряют деньги 74–89 % розничных счетов
  ([ESMA](https://www.esma.europa.eu/node/84933)); в текущих раскрытиях крупных брокеров — около 70 %.

Что из этого следует для бота:
1. **Не соревноваться в скорости.** Любой паттерн на минутах и часах ИИ и HFT находят раньше, а спред
   розничного счёта (1,4–3,5 пункта) съедает остаток. Поэтому по умолчанию — дневные свечи: сделок меньше,
   доля издержек ниже.
2. **Не стоять там, где стоят все.** Стопы на «очевидных» уровнях (круглые числа, свежие экстремумы, уровни,
   которые видит любой ИИ-бот) — первые кандидаты на вынос. Бот ставит стоп по волатильности (ATR), а не по уровню.
3. **Риск важнее сигнала.** На рынке с «вспышками» волатильности выживает тот, у кого жёсткие лимиты: 1 % на
   сделку, дневной стоп, аварийная остановка — всё это в боте есть и срабатывает без вас.
4. **Проверять только на будущем.** Если стратегию можно найти перебором истории, её уже нашли тысячи ИИ-ботов.
   Отсюда лаборатория стратегий (ниже).

### Проверка на 10 парах за 10 лет

8 кандидатов со стандартными параметрами из литературы, 10 пар (EURUSD, GBPUSD, USDJPY, AUDUSD, USDCAD,
USDCHF, NZDUSD, EURJPY, GBPJPY, EURGBP), дневные цены закрытия Yahoo Finance с ноября 2016 года,
спреды Альфа-Форекс, риск 1 %. Выбор — по 2016–2021, проверка — на 2022–2026, которые в выборе не участвовали.
Повторить: `python research/strategy_study.py`.

| Стратегия | 2016–21, %/год | Шарп | 2022–26, %/год | Шарп | Просадка |
|---|---|---|---|---|---|
| Стоимость (против 3-летнего изменения) | +2,53 | **+1,06** | −0,19 | −0,06 | 8,2 % |
| Разворот 3 мес | −0,51 | −0,14 | +0,86 | +0,23 | 5,8 % |
| Импульс 12 мес | −0,70 | −0,20 | +0,31 | +0,09 | 8,5 % |
| Дончиан 55/20 («черепахи») | −0,63 | −0,22 | −2,46 | −0,80 | 14,0 % |
| **RSI(2) возврат** (по умолчанию в боте) | −0,42 | −0,27 | +0,29 | +0,19 | **3,1 %** |
| Импульс 3 мес | −1,10 | −0,31 | −2,66 | −0,70 | 16,8 % |
| EMA 50/200 | −1,78 | −0,47 | −1,61 | −0,44 | 15,9 % |
| Импульс-ансамбль 1–12 мес (как у CTA-фондов) | −1,35 | −0,50 | −1,71 | −0,61 | 12,6 % |
| *Случайные направления (30 прогонов)* | | | | *−0,12 (90 %: −0,65…+0,49)* | |

Старая часовая стратегия (`ema_cross`) на часовых свечах 2024–2026 потеряла 12–16 % на каждой из трёх пар.

**Выводы.**
- Лучшая на истории стратегия («стоимость», Шарп +1,06) на новых данных дала −0,06. Это и есть подгонка: то,
  что лучше всего выглядит в прошлом, не обязательно работает в будущем.
- **Ни одна** стратегия на новых данных не вышла за пределы того, что дают случайные входы. Доказанного
  преимущества нет ни у одной.
- По умолчанию выбран **RSI(2) на дневках**: не потому, что он «прибыльный», а потому, что у него самая
  маленькая просадка (3,1 %), мало сделок и меньше всего потерь на издержках. Это самый безопасный вариант
  для наблюдения за ботом на демо-счёте.
- Трендовые подходы в 2016–2026 на валютах работали плохо, что совпадает с научными данными выше.

### Лаборатория стратегий

Раз прошлое не может честно выбрать стратегию, её выбирает будущее. Лаборатория (`alfabot/lab.py`) запоминает
дату запуска бота и с этого дня каждый день ведёт **виртуальный портфель по каждому из 8 кандидатов** на 10
парах. Эти данные невозможно подогнать: их не было, когда стратегии выбирались. По субботам в Telegram приходит
рейтинг, в любой момент — по команде `/lab`. Надёжные выводы — не раньше чем через ~6 месяцев. Если какая-то
стратегия будет устойчиво лидировать, её можно включить в боте (если её ещё нет в списке — добавить в
`alfabot/strategies.py`).

**Откуда свечи.** Историю свечей бот берёт с Yahoo Finance (бесплатно; для мажорных пар цены закрытия
практически совпадают с брокерскими, а дневные high/low у Yahoo бывают с выбросами, поэтому дневные стратегии
считают волатильность только по закрытиям). Цены входа, SL и TP считаются от котировок самого терминала. Параллельно бот копит
собственные свечи из котировок терминала (`data/bars`) и переключается на них, если Yahoo недоступен.

## Если что-то сломалось

Брокер может обновить веб-терминал, и тогда кнопки или таблицы окажутся на другом месте. Бот пришлёт в Telegram
ошибку и скриншот. Все селекторы собраны в одном месте, в классе `Sel` в `alfabot/web/terminal.py`, поэтому
пришлите скриншот или вывод `python run_web.py --check`, и их можно быстро поправить. Открытые сделки при этом
защищены стоп-лоссом и тейк-профитом на стороне брокера, даже если бот остановился.

## Альтернатива: через программу MetaTrader 5

Если вы всё же поставите MT5, есть два варианта с той же стратегией.

- **Советник `mql5/AlfaTrendEA.mq5`.** Скопируйте его в `MQL5/Experts` (меню «Файл → Открыть каталог данных»),
  скомпилируйте клавишей F7 в MetaEditor и перетащите на график. Можно перенести на виртуальный хостинг MT5
  (правый клик по счёту → «Зарегистрировать виртуальный сервер»). Тогда он работает 24/7 без вашего компьютера.
  На реальном счёте советник не торгует, пока не включён `InpAllowReal`.
- **Python-бот `run_bot.py`** работает через официальный пакет `MetaTrader5` (только Windows):
  `python check_connection.py`, затем `scripts\start_bot.bat` или `register_autostart.ps1 -Mt5`.
