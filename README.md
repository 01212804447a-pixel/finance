# AlfaBot: автономная торговля на Альфа-Форекс (MetaTrader 5)

Альфа-Форекс работает на **MetaTrader 5**. Веб-терминал `trade.alfaforex.ru/terminal`
и программа MT5 подключаются к одному и тому же счёту. Поэтому сделки бота сразу видны
в веб-терминале и в мобильном приложении.

Автоматизировать сам веб-терминал (кликать кнопки в браузере) плохая идея. Его
протокол зашифрован и обфусцирован, любое обновление сайта сломает бота, а брокер может
счесть это нарушением правил. У MT5 есть **официальные** способы автоторговли, и проект
использует именно их:

| Вариант | Где работает | Насколько автономно | Что нужно от вас |
|---|---|---|---|
| **A. Советник `mql5/AlfaTrendEA.mq5` + виртуальный хостинг MT5** (рекомендуется) | Серверы MetaQuotes, 24/7 | Максимально: компьютер можно выключить | Один раз установить, ~$10–15/мес за хостинг |
| B. Советник на своём ПК | Ваш Windows-ПК с открытым MT5 | Пока ПК включён | Не выключать ПК |
| C. Python-бот `alfabot` | Windows-ПК или Windows-VPS | 24/7 на VPS, автоперезапуск, Telegram-управление | Windows-VPS (~500–1000 ₽/мес) |

В вариантах A и C логика одна и та же.

## Стратегия (одинаковая в советнике и в Python-боте)

- **Вход** по закрытому бару, без перерисовки. BUY ставится, когда EMA20 пересекает EMA50 снизу вверх,
  цена выше EMA200 (тренд вверх), ADX ≥ 20 (тренд есть) и RSI < 70. SELL зеркально.
- **Выход**: стоп-лосс 1.5 ATR, тейк-профит 3 ATR (1:2). После +1 ATR стоп переносится в
  безубыток, после +1.5 ATR включается трейлинг-стоп. Сделка также закрывается при
  обратном пересечении EMA.
- **Риск-менеджмент**:
  - 1 % средств на сделку, объём считается автоматически;
  - **дневной стоп −3 %**: бот закрывает всё и до следующего дня не торгует;
  - **аварийная остановка при −15 % от пика**: бот останавливается до ручного сброса;
  - не больше 3 позиций, фильтр широкого спреда;
  - торговля только с 06:00 до 20:00 UTC (09:00–23:00 МСК), без новых сделок в пятницу вечером,
    закрытие всех позиций перед выходными;
  - **защита от реального счёта**: пока вы явно не разрешите (`allow_real` / `InpAllowReal`),
    бот торгует только на демо;
  - ручные сделки и сделки других советников бот не трогает (они отличаются по magic-номеру).

> ⚠️ Прибыль не гарантирует ни одна стратегия. Форекс с плечом может быстро съесть депозит.
> Минимум 2–4 недели гоняйте бота на **демо-счёте** и только потом переходите на реальный.

## Вариант A. Советник на виртуальном хостинге MT5 (рекомендуется)

1. Скачайте MetaTrader 5 на сайте Альфа-Форекс (<https://alfaforex.ru/metatrader/>), установите.
2. Откройте демо-счёт (<https://alfaforex.ru/demo-account/>) и войдите в него в MT5.
3. В MT5 выберите **Файл → Открыть каталог данных**, перейдите в `MQL5/Experts` и скопируйте туда
   `mql5/AlfaTrendEA.mq5`.
4. Нажмите **F4** (MetaEditor), откройте файл и нажмите **F7** (Компилировать). Ошибок быть не должно.
5. В MT5 откройте любой график, например EURUSD H1, и перетащите на него советник из «Навигатора».
   Во вкладке «Общие» включите **«Разрешить алготорговлю»**, во вкладке «Входные параметры» проверьте
   символы и риск. На панели инструментов должна гореть кнопка **«Алготорговля»**.
6. Push-уведомления на телефон: установите мобильное приложение MetaTrader 5 и откройте
   *Настройки → Сообщения → MetaQuotes ID*. Этот ID вставьте в настольном MT5 в
   *Сервис → Настройки → Уведомления*.
7. Работа 24/7 без вашего ПК: в «Навигаторе» щёлкните правой кнопкой по счёту и выберите
   **«Зарегистрировать виртуальный сервер»**. Выберите ближайший к брокеру сервер и оплатите, затем
   выполните **«Миграцию»** (переносятся эксперты и настройки). После этого MT5 на ПК можно закрыть.

**Проверка на истории:** *Вид → Тестер стратегий*, советник AlfaTrendEA, «Каждый тик на основе
реальных тиков», период от года. В режиме мультивалютности советник сам подгрузит все символы.

## Вариант C. Python-бот (Windows-ПК или Windows-VPS)

Официальный Python-пакет `MetaTrader5` работает **только на Windows** и рядом с запущенным
терминалом MT5.

```powershell
git clone <этот репозиторий>; cd finance
PowerShell -ExecutionPolicy Bypass -File scripts\install_windows.ps1
```

1. Откройте MT5, войдите в счёт Альфа-Форекс (сначала демо) и включите кнопку **«Алготорговля»**.
   В *Сервис → Настройки → Советники* поставьте галочку «Разрешить алгоритмическую торговлю».
2. Отредактируйте `config.yaml`. Поля `login/password/server` можно не заполнять, если терминал уже
   залогинен. Пароль лучше задать переменной окружения `ALFA_PASSWORD`.
3. Проверьте подключение (эта команда ничего не торгует):
   ```powershell
   .\.venv\Scripts\python.exe check_connection.py
   ```
4. Проверьте стратегию на истории своего брокера:
   ```powershell
   .\.venv\Scripts\python.exe backtest.py --mt5 EURUSD --bars 20000
   ```
5. Запустите бота:
   ```powershell
   scripts\start_bot.bat
   ```
   Для полной автономии зарегистрируйте автозапуск (PowerShell от администратора). Бот будет
   стартовать при входе в Windows и перезапускаться после сбоя:
   ```powershell
   PowerShell -ExecutionPolicy Bypass -File scripts\register_autostart.ps1
   ```
   В самом MT5 тоже включите автозапуск: добавьте ярлык `terminal64.exe` в `shell:startup`.
   На VPS настройте автологин Windows.

### Управление через Telegram (необязательно)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Напишите своему боту любое сообщение и узнайте свой `chat_id`, например через @userinfobot.
3. В `config.yaml` укажите `telegram.enabled: true`, `token`, `chat_id`. Токен можно задать
   переменной окружения `TG_TOKEN`.

Бот присылает уведомления о входах, выходах, срабатывании лимитов, ошибках связи и итоги дня.
Он понимает команды от вас (сообщения из чужих чатов игнорирует):

| Команда | Действие |
|---|---|
| `/status` | баланс, средства, открытые позиции |
| `/pause` | не открывать новые сделки (открытые продолжают сопровождаться) |
| `/resume` | продолжить торговлю |
| `/closeall` | закрыть все позиции бота и поставить его на паузу |

### Переход на реальный счёт

Только после того как демо-результаты вас устроят:

1. войдите в MT5 под реальным счётом;
2. в `config.yaml` поставьте `account.allow_real: true` (в советнике: `InpAllowReal = true`);
3. начните с минимального риска, например `risk_per_trade_pct: 0.5`.

Если сработала аварийная остановка по просадке, бот сам больше не торгует. Сначала разберитесь в
причине, затем удалите `state.json` (у советника удалите глобальные переменные `AlfaTrend_*`,
клавиша F3 в MT5).

## Разработка

```bash
pip install -r requirements-dev.txt
pytest -q
```

Тесты идут на Linux без MT5: модуль `MetaTrader5` подменяется фейком (`tests/helpers.py`).

```
alfabot/indicators.py   EMA, RSI, ATR, ADX (Wilder)
alfabot/strategy.py     сигналы, уровни SL/TP, безубыток/трейлинг
alfabot/risk.py         размер позиции, дневной стоп, аварийная остановка
alfabot/broker.py       обёртка MetaTrader5: символы, котировки, ордера
alfabot/bot.py          главный цикл, расписание, Telegram-команды, переподключение
alfabot/backtest.py     бэктест той же стратегии
mql5/AlfaTrendEA.mq5    та же логика в виде советника MT5
```

Индикаторы ATR в MT5 и в Python сглаживаются немного по-разному, поэтому сигналы советника и
Python-бота могут изредка расходиться на один бар. Не запускайте оба варианта на одном счёте с
одинаковым magic-номером.
