# AlfaBot: автономная торговля на Альфа-Форекс

Бот торгует **через браузерный веб-терминал** `trade.alfaforex.ru/terminal`. Программу MetaTrader 5
ставить не нужно. Бот сам открывает терминал в скрытом браузере Chromium, входит в ваш счёт,
читает баланс, позиции и котировки и нажимает те же кнопки, что и вы: открывает сделки сразу со
стоп-лоссом и тейк-профитом, подтягивает стоп и закрывает позиции. Вы управляете им из **Telegram**.

```
 Yahoo Finance ──(история свечей)──┐
                                   ▼
 Telegram  ◄──уведомления──  AlfaBot (Python)  ──Playwright──►  Chromium  ──►  trade.alfaforex.ru/terminal
           ──команды──────►   стратегия + риск                                  (ваш счёт)
```

**Что проверено вживую.** Веб-терминал Альфы — это стандартный MT5 Web Terminal от MetaQuotes. Весь цикл
проверен на демо-счёте того же терминала MetaQuotes:
- вход, чтение баланса, позиций и котировок;
- открытие BUY и SELL сразу с SL/TP;
- перенос стопа и закрытие;
- 5-значные (EURUSD) и 3-значные (USDJPY) пары, пересчёт объёма через курс валют;
- полный цикл бота, когда он сам открывает и закрывает сделки.

Форма входа у Альфы такая же. Повторить проверку можно скриптом `scripts/web_smoke_test.py`, он работает
только на демо-счёте.

## ⚠️ Важно про безопасность

- По умолчанию бот работает в **бумажном режиме**: котировки настоящие, сделки виртуальные, в терминал ничего
  не отправляется. Результаты видны в Telegram по команде `/stats`.
- Режим **«Ордера на счёт»** — бот открывает сделки в терминале. На **демо-счёте** (виртуальные деньги) это
  безопасно: «Проверить вход» показывает, демо у вас счёт или реальный.
- На **реальном** счёте ордера уходят, только если дополнительно стоит галочка «Разрешить реальные деньги»
  (в файлах — `BOT_MODE=live` в `.env` и `account.allow_real: true` в `config.yaml`).
- Бот трогает только свои сделки, помеченные комментарием `alfabot`. Ваши ручные сделки он не закрывает.
- Прибыль не гарантирует ни одна стратегия. Сначала 2–4 недели гоняйте бумажный режим, потом начинайте с малого
  риска.

## Быстрый старт на своём компьютере (Windows)

1. **Скачайте бота:**
   [ZIP-архив](https://github.com/01212804447a-pixel/finance/archive/refs/heads/claude/zen-bohr-17bdcp.zip).
   Распакуйте его, например, в `C:\AlfaBot`.
2. Дважды щёлкните **`1-install.bat`**. Он поставит Python (если его нет), нужные пакеты и браузер
   (примерно 5 минут). В конце сам откроется окно настроек.
3. В окне **«AlfaBot — настройка»** заполните поля сверху вниз:

   | Поле | Что вписать |
   |---|---|
   | Логин (номер счёта) | номер вашего счёта Альфа-Форекс, только цифры |
   | Пароль | пароль от этого счёта (тот же, что на trade.alfaforex.ru/terminal) |
   | Токен бота | токен от @BotFather, например `123456789:AA...` |
   | Мой chat_id | не вписывайте вручную: нажмите **«Найти мой chat_id»**, в открывшемся Telegram нажмите «Старт», и поле заполнится само. Бот пришлёт вам «✅ AlfaBot подключён» |
   | Валютные пары | можно оставить как есть |
   | Риск на сделку | 1 % — стандарт, 0.5 % — осторожнее |
   | Режим | **Бумажный** — сделки виртуальные. Если счёт демо, можно выбрать **«Ордера на счёт»**: сделки будут видны прямо в терминале |
   | Разрешить реальные деньги | не ставьте, пока не убедитесь в результатах |

   Затем нажмите **«Проверить вход»**. Через 1–2 минуты внизу появится ваш баланс и котировки.
   После этого нажмите **«Запустить бота»**.
4. Откроется чёрное окно **AlfaBot**: это и есть работающий бот. Пока оно открыто, бот торгует.
   Если закрыть окно, бот остановится. Чтобы запустить его снова, нажмите **`3-start.bat`**.
   Поменять настройки можно через **`2-settings.bat`**. Обновить бота до последней версии: закройте его окно
   и запустите **`4-update.bat`** (настройки сохранятся).

Советы для работы на своём компьютере:
- В настройках есть галочка «Запускать бота автоматически при включении компьютера».
- Отключите спящий режим (*Параметры → Система → Питание*): когда компьютер спит, бот не работает.
  При этом открытые сделки всё равно защищены стоп-лоссом и тейк-профитом на стороне брокера.
- Логин, пароль и токен хранятся только у вас, в файле `.env` в папке бота. Никому его не отправляйте.

**macOS/Linux:** выполните в терминале `./1-install.sh` (откроется то же окно настроек), затем запустите `./3-start.sh`.

## Запуск на сервере 24/7 (по желанию, позже)

Если не хочется держать компьютер включённым, арендуйте VPS на Linux (~300–600 ₽/мес).
Создайте на своём компьютере файлы `.env` и `config.yaml` через окно настроек и скопируйте их на сервер.
Затем:

```bash
docker compose up -d --build
```

Проверка без торговли и логи:

```bash
docker compose run --rm alfabot python run_web.py --check
```

```bash
docker compose logs -f
```

## Telegram

Токен даёт @BotFather (`/newbot`). chat_id окно настроек находит само по кнопке «Найти мой chat_id».

Раз в час (в торговые часы) бот присылает короткий отчёт: что он видит по каждой паре и почему пока не входит.
Отключается галочкой в настройках. Также бот присылает уведомления о каждом входе и выходе, о срабатывании лимитов, итоги дня, а при ошибке — скриншот
терминала. Команды он принимает только из вашего чата:

| Команда | Действие |
|---|---|
| `/status` | баланс, средства, открытые позиции |
| `/market` | что бот видит по каждой паре и какого сигнала ждёт |
| `/stats` | статистика (в бумажном режиме — по виртуальным сделкам) |
| `/screenshot` | снимок веб-терминала прямо сейчас |
| `/pause` / `/resume` | остановить или возобновить открытие новых сделок |
| `/closeall` | закрыть все сделки бота и встать на паузу |

## Переход на реальную торговлю

1. После нескольких недель в бумажном режиме проверьте `/stats`.
2. Откройте `2-settings.bat`, выберите **«Ордера на счёт»**, поставьте галочку **«Разрешить реальные деньги»**,
   при желании уменьшите риск и подтвердите.
3. Закройте окно бота и запустите `3-start.bat` заново.

## Стратегия и риск-менеджмент

- **Вход** по закрытой часовой свече, без перерисовки. BUY ставится, когда EMA20 пересекает EMA50 снизу
  вверх, цена выше EMA200, ADX ≥ 20 и RSI < 70. SELL зеркально.
- **Выход**: стоп 1.5 ATR, тейк 3 ATR. После +1 ATR стоп переносится в безубыток, дальше работает
  трейлинг 1.5 ATR. Сделка также закрывается при обратном пересечении EMA.
- **Риск**:
  - 1 % средств на сделку, объём считается автоматически, потолок `max_lot`;
  - **дневной стоп −3 %**: бот закрывает всё и до завтра не торгует;
  - **аварийная остановка при −15 % от пика**;
  - не больше 3 позиций, фильтр спреда;
  - торговля с 09:00 до 23:00 МСК, без новых сделок вечером в пятницу, закрытие перед выходными.
- Все параметры настраиваются в `config.yaml`. Проверить стратегию на истории можно так:
  `python backtest.py --csv EURUSD_H1.csv`.

### Честно о результатах на истории

Стратегия по умолчанию даёт около **0,5 сигнала в неделю на пару**: несколько сделок в неделю на три пары,
иногда тишина 1–2 недели. Это нормально — бот работает, просто ждёт сигнала (`/market` покажет, чего именно).

Проверка на реальных часовых свечах января 2024 – ноября 2026 со спредами Альфа-Форекс (1,4–2,1 пункта) показала,
что стратегия **убыточна**:

| Пара | Сделок | Прибыльных | Коэфф. прибыли | Итог при риске 1 % |
|---|---|---|---|---|
| EURUSD | 75 | 32 % | 0,70 | −12 % |
| GBPUSD | 72 | 26 % | 0,64 | −13 % |
| USDJPY | 77 | 26 % | 0,59 | −16 % |

Я также проверил 8 других популярных подходов (пересечение EMA на H4 и D1, RSI(2), пробой канала Дончиана,
возврат к средней по Боллинджеру) с проверкой на отложенных данных. **Ни один** не дал стабильной прибыли на всех
трёх парах: по отдельности результаты не отличались от случайных входов за вычетом спреда. Проверка самого
бэктестера: случайные входы без спреда дают коэффициент прибыли 1,01, со спредом — 0,88, как и должно быть.

Вывод: бот надёжно исполняет сделки и держит риск, но **прибыльной стратегии в нём сейчас нет**. Подгонять
параметры под историю я не стал: это даёт красивые цифры в прошлом и убытки в будущем. Используйте бумажный
режим или демо-счёт, а на реальные деньги переходите, только если у вас есть стратегия с подтверждённым
преимуществом.

**Откуда свечи.** Историю часовых свечей бот берёт с Yahoo Finance (бесплатно, для мажорных пар она практически
совпадает с брокерской). Цены входа, SL и TP считаются от котировок самого терминала. Параллельно бот копит
собственные свечи из котировок терминала (`data/bars`) и переключается на них, если Yahoo недоступен.

## Если что-то сломалось

Брокер может обновить веб-терминал, и тогда кнопки или таблицы окажутся на другом месте. Бот пришлёт в Telegram
ошибку и скриншот. Все селекторы собраны в одном месте, в классе `Sel` в `alfabot/web/terminal.py`, поэтому
пришлите скриншот или вывод `python run_web.py --check`, и их можно быстро поправить. Открытые сделки при этом
защищены стоп-лоссом и тейк-профитом на стороне брокера, даже если бот остановился.

## Альтернатива: через программу MetaTrader 5

Если вы всё же поставите MT5, есть два варианта с той же стратегией.

- **Советник `mql5/AlfaTrendEA.mq5`.** Скопируйте его в `MQL5/Experts` (меню «Файл → Открыть каталог данных»),
  скомпилируйте клавишей F7 в MetaEditor и перетащите на график. Можно перенести на виртуальный хостинг MT5
  (правый клик по счёту → «Зарегистрировать виртуальный сервер»). Тогда он работает 24/7 без вашего компьютера.
  На реальном счёте советник не торгует, пока не включён `InpAllowReal`.
- **Python-бот `run_bot.py`** работает через официальный пакет `MetaTrader5` (только Windows):
  `python check_connection.py`, затем `scripts\start_bot.bat` или `register_autostart.ps1 -Mt5`.
